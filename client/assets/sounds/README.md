# Egne lydfiler

Vælg **Egne lydfiler** under Indstillinger → Signallyd, og læg filer med disse navne i denne mappe
(`.mp3`, `.wav` eller `.ogg`):

| Fil | Bruges til |
|---|---|
| `signal-single.mp3` | **1 lydsignal** (opmærksomhed, varsel, klar, start) |
| `signal-long.mp3` | **1 langt lydsignal** (et-minut-signalet) |
| `signal-short.mp3` | kort stød (fx målgang) |

Mangler en fil, bruges den indbyggede signalhorn i stedet. Brug kun lyde, du har ret til at bruge.
